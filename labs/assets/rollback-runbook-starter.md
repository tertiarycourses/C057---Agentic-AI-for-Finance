# C057 Rollback Runbook Starter

- Trigger: failed high-risk route, wrong material figure, prohibited action attempt, or unavailable critical service.
- Decision authority: Finance Control Owner with the Business Owner.
- Disable action: stop new runs and disable the affected agent identity.
- Access revocation: AI Platform Owner revokes credentials and active sessions.
- In-flight queue: freeze, label, and preserve every item.
- Manual fallback: return work to the approved manual process owner.
- Notification: inform Business, Data, Technology, and Control Owners.
- Evidence preservation: retain run evidence, event logs, outputs, reviewer changes, and decisions.
- Correction and retest: fix the control and rerun the full applicable evaluation suite.
- Restart approval: Business Owner and Finance Control Owner approve only after reconciliation.
